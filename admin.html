Site Admin

Manage gallery photos and class sponsors. Changes go live on the site within about a minute.

Connection

Needs a GitHub Personal Access Token to save changes. This stays only in this browser - it's never uploaded or shared anywhere except directly to GitHub. Open GitHub token settings → "Fine-grained tokens" tab → Generate new token → under "Repository access" choose "Only select repositories" and pick this one → under "Permissions" set "Contents" to "Read and write".
